# AUC Plugin
AUC (Answer Until Correct) ist ein Question Behaviour Plugin, das auf dem bereits existierenden "interactive" Question Behaviour aufbaut. Im Unterschied zu dem "interactive" Question Behaviour werden bei AUC alle zuvor ausgesuchten falschen Antwortoptionen ausgeblendet und es ist Studierenden erst dann möglich, zur nächsten Frage zu gelangen, wenn die aktuelle Frage korrekt gelöst wurde. Aus diesem Grund sollte AUC nur in Kombination mit einer sequenziellen Navigation verwendet werden.
(Bisher wurde das Plugin nur für Moodle Version 4.5 getestet)

## Installation
Das Plugin kann installiert werden, indem der Code unter moodle/question/behaviour eingefügt wird.
